Attitude / piloting

W/S pitch · A/D yaw · Q/E roll. Rotations change the actual 3D thrust vector. ↑/↓ throttle. Shift afterburner · B brake. Heat limits continuous burn.

Advanced flight console

J/L strafe · U/O ascend/descend · F toggle inertial assist · T cycle target · Space maneuver pulse · P pause. Targets and radar are simulated noncombat game cues.

Gamepad and mission rules

Gamepad: left stick pitch/yaw, right stick roll/throttle, triggers brake/afterburner, shoulders strafe, A pulse, X target, Y assist, Start pause. Shield absorbs limited debris hits; Moon impact can end the flight. Scores are local practice only.

3D space + time = four-coordinate state; this is not a fourth spatial dimension or real general relativity. Military-style interface is fictional game UX. No real spacecraft control guidance, online combat, paid entry, prizes, Stripe integration or authenticated leaderboard. All ship geometry, UI and visual assets are original.
