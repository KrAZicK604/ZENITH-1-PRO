NASA/JPL Interplanetary Navigation

Calculate the three-dimensional center-to-center separation implied by supplied position vectors between Earth, the Moon and Mars for one ephemeris epoch. All three vectors must come from NASA/JPL Horizons in the same barycentric ICRF reference frame, KM-S units and TDB timestamp. This module never invents a current position.

Published reference ranges (not today's positions)

Earth → Moon mean384,400 km
Earth → Mars approximate minimum54.6 million km
Earth → Mars approximate maximum401.4 million km

Moon → Mars has no single fixed distance. The value is computed from the submitted vectors only when all three date-matched positions are provided; the submitted source is not independently authenticated. Straight-line separation is not spacecraft route length, flight duration or fuel requirement.

Load Horizons position vectors (offline)

Use JPL Horizons with target body 399 (Earth), 301 (Moon), then 499 (Mars). For all three: Ephemeris type Vector Table, center Solar System Barycenter (500@0), reference frame ICRF, reference plane FRAME (equatorial, not ECLIPTIC), vector correction NONE (geometric), output units KM-S, time scale TDB, non-CSV vector table with positions (e.g. VEC_TABLE=2), and exactly one shared TDB epoch. Copy the complete plain-text results including the header and $$SOE/$$EOE markers into the corresponding fields.
